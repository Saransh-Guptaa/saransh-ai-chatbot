# 🤖 Saransh's AI Chatbot

A conversational AI chatbot built with Google Gemini API and Streamlit.
Built by **Saransh Gupta** — CSE + Applied AI, 1st Year.

## ✨ Features
- Real-time AI responses powered by Gemini 1.5 Flash
- Clean chat interface
- Conversation memory within session
- Deployed live on Streamlit Cloud

## 🛠 Tech Stack
- Python
- Google Gemini API
- Streamlit
- python-dotenv

## 🚀 Run locally

1. Clone this repo
```bash
   git clone https://github.com/saranshgupta/saransh-ai-chatbot
   cd saransh-ai-chatbot
```

2. Install dependencies
```bash
   pip install -r requirements.txt
```

3. Add your API key — create a `.env` file
```
   GEMINI_API_KEY=your_key_here
```

4. Run the app
```bash
   streamlit run app.py
```
